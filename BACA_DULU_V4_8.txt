PANDUAN INSTALASI WINDOWS
1. Backup V4.7 terakhir yang saat ini berfungsi.
2. Copy config.js yang sudah bekerja dari V4.7 ke folder V4.8 ini.
3. Jika sudah ada link Google Form, pindahkan feedback-config.js aktif.
4. Deploy folder website lengkap pada project NETLIFY yang SAMA.
5. Setelah Published, periksa menu Info Parkir UI, filter, halaman Pusat Bantuan,
   pilihan Motor/Mobil, Peta dan login Admin.
6. JANGAN menempelkan SERVICE_ROLE key di website!

Tidak perlu SQL untuk Tahap 2. Tidak mengubah zona, akun, penugasan,
penghitungan atau kapasitas Supabase.
